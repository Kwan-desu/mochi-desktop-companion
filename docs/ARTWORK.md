# Transparent AZKi assets

Generated with the built-in imagegen tool from the user's three original opaque PNGs. Originals were preserved. Final files: `azki/normal.png`, `azki/angry.png`, `azki/puffyface.png` under `assets/` (originals are in `assets/originals/azki/`). These generated cutouts can have slight edge or detail differences from the originals.

The following prompt was sent once per image, replacing `{expression}` with `normal`, `angry`, and `puffyface` and referencing the corresponding original file:

> Edit the provided {expression} expression character image: remove ONLY the opaque black background and replace it with genuine transparent alpha. Preserve the exact full-body character, face expression, pose, hair, fingers, outfit and boots, proportions and framing. No redesign, no added objects, no shadow, no border, no checkerboard baked into pixels. Asset for transparent desktop sprite. Return PNG with actual transparent background. Keep the full figure and same aspect ratio.
