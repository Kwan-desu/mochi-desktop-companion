# Mochi Desktop Companion 1.1.0

## New in this version

- Optional taskbar wandering, bouncing, and rest animations using your companion artwork.
- Always-on-top setting and right-click pause/resume walking.
- Opt-in AI chatter every few minutes while minimized (uses your API quota).
- Settings shows whether API keys were loaded; keys remain encrypted locally.

## Downloads

- **Portable.exe** — one executable; download and run, no installation required. Bundles .NET and character artwork. The first launch extracts bundled runtime files to a temporary cache.
- **Setup.exe** — per-user installer with Start menu shortcuts, optional desktop shortcut, and Windows uninstall support. No administrator access or separate .NET installation required.
- **SHA256SUMS.txt** — checksums for both downloads.

For **Windows 10 (1809+) or Windows 11, x64**. Both options store settings, history, and custom companions in `%LOCALAPPDATA%\MochiDuo`; portable means no installation, not that personal data travels beside the executable. Uninstall preserves this personal data.

Includes solo/duo conversation, custom companions, transparent desktop characters, output language and reply length controls, chat history, fallback API keys, and synchronized Fish Audio playback with the next reply prepared ahead.

Add your own Google and Fish Audio API keys in Settings and click Save settings. Provider quotas and fees apply. No keys, private chat history, or user-created companions are included in these downloads.

The application binaries are unsigned. Windows may show an unknown-publisher warning.
